# rclone source audit for LedgeSync

Reviewed on 2026-10-01. This is a scoped implementation review, not a complete security audit or a claim of rclone feature compatibility. The real official repository was cloned outside the project and upload roots. Baseline: **v1.75.1**, full commit **687d264b689b8c49a67e2e52a8a5e0caa01c04ce**, released 2026-09-04T17:11:27Z. The commit timestamp is 2026-09-04T17:03:20+01:00. Machine-readable hashes, tool versions, review inventory and test evidence are in [UPSTREAM_BASELINE.json](UPSTREAM_BASELINE.json).

The official GitHub releases API returned this stable, non-draft, non-prerelease release at retrieval. GitHub displayed a verified tag signature; local GPG verification was **not performed**. The local checkout is detached and clean. Upstream `go.mod` requires Go 1.26.0; the local test toolchain was Go 1.27.0 on darwin/arm64.

Every upstream link below pins the same full baseline commit. **Observed** describes inspected code; **inference** describes implications for our contract; **decision** describes LedgeSync behavior. Associated tests are evidence sources, not automatically evidence that they were executed.

## Entry points and shared interfaces

**Observed:** [`rclone.go:6–15`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/rclone.go#L6-L15) registers all backends, commands and plugins and calls `cmd.Main`. [`cmd/sync/sync.go:96–106`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/cmd/sync/sync.go#L96-L106) enters `sync.Sync`; copy enters `sync.CopyDir` in [`cmd/copy/copy.go:122–133`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/cmd/copy/copy.go#L122-L133). `cmd.Run` retries the whole operation using config and accounting state ([`cmd/cmd.go:240–280`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/cmd/cmd.go#L240-L280)).

`Fs`, `Info`, `Object` and `ObjectInfo` are useful interface examples ([`fs/types.go:17–123`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/types.go#L17-L123)), but express path-oriented backend operations rather than immutable, authorized LedgeSync operations. `fs.FileExists` treats permission-denied as false ([`fs/fs.go:85–95`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/fs.go#L85-L95)); that helper must not become evidence of remote absence in our planner.

**Decision:** implement narrow application ports and one shared core. Do not call upstream commands. Relevant regression references: `fs/operations/copy_test.go:103–148` and `fs/sync/sync_test.go:184–199` for copy and missing directories; these mutation-oriented suites were inspected but not run.

## Filter parsing, matching and directory traversal

**Observed:** `rules.include` returns the first matching rule and otherwise true ([`fs/filter/rules.go:93–115`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/rules.go#L93-L115)). `forEachLine` trims whitespace, ignores empty/comment lines beginning `#` or `;`, propagates open/scanner errors, and permits stdin when the path is `-` ([`rules.go:134–168`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/rules.go#L134-L168)). `addRule` accepts `+ `, `- ` and standalone reset `!`; other syntax is an error ([`rules.go:182–192`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/rules.go#L182-L192)). Include/include-from adds one final `/**` exclusion; filter-from alone does not ([`rules.go:212–275`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/rules.go#L212-L275)).

`GlobPathToRegexp`/`globToRegexp` handle root anchoring, `*`, `**`, `?`, character classes, escapes, nested brace alternatives, raw regexp sections and ignore-case. Invalid star counts and mismatched constructs return errors ([`fs/filter/glob.go:15–207`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/glob.go#L15-L207)). These functions can be extracted with only standard-library imports. Directory inference handles difficult braces/regexp conservatively by including all directories ([`glob.go:210–259`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/glob.go#L210-L259)); its sole `fs` use is an informational log. `Filter.Add` converts trailing-slash exclusion to `/**`, distinguishes file and directory rules, and infers directory rules for includes and `*` ([`filter.go:317–363`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter.go#L317-L363)).

**Inference:** copying only glob conversion does not confer whole rclone-filter compatibility: stream order/reset, implicit include fallback and directory barriers still need differential tests. Gitignore last-match and ignored-parent behavior must remain a separate grammar. Our explanation requires source mechanism, file, line, scope and raw rule, absent from the small upstream `rule` struct ([`rules.go:25–29`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/rules.go#L25-L29)). Direct package import initializes global filter options ([`filter.go:24–25`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter.go#L24-L25), [`163–174`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter.go#L163-L174)) and can fall back to global config ([`703–735`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter.go#L703-L735)).

**Decision:** adapt the bounded pure glob implementation with MIT provenance; build our own immutable source/group layer. Preserve upstream tests as behavioral references. Associated tests actually executed: `TestGlobStringToRegexp`, `TestGlobPathToRegexp`, `TestGlobToDirGlobs` ([`glob_test.go:10–204`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/glob_test.go#L10-L192)), match tests including case and regexp ([`filter_test.go:530–627`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter_test.go#L530-L627)), directory-rule tests ([`715–793`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter_test.go#L715-L793)) and whitespace/scanner tests ([`795–916`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/filter/filter_test.go#L795-L916)).

## Walking, copy, sync and verification

**Observed:** `walk` bounds workers by `ci.Checkers`, checks cancellation, serializes callbacks and lets the callback mask/propagate listing errors ([`fs/walk/walk.go:367–464`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/walk/walk.go#L367-L464)). Associated tests explicitly exercise not-found masking and skip behavior, levels, errors and recursive traversal ([`walk_test.go:190–444`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/walk/walk_test.go#L190-L444)); not executed here.

`sync.run` begins checking/transferring/deleting workers and runs a live source/destination march; `checkFirst` delays transfer but does not supply an externally approved immutable plan ([`fs/sync/sync.go:936–1019`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/sync/sync.go#L936-L1019)). Deletion after errors is blocked unless `IgnoreErrors`; spare destinations are selected from maps and passed to deletion helpers ([`sync.go:627–665`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/sync/sync.go#L627-L665)).

`copy.updateOrPut` can update existing objects; failed copy cleanup can delete partial or corrupted destinations. `verify` checks size and available hashes, ignoring blank hashes ([`fs/operations/copy.go:213–359`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/operations/copy.go#L213-L359)). `Copy` reads config, supports dry-run through `SkipDestructive`, and chooses common hashes ([`copy.go:390–424`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/operations/copy.go#L390-L424)). Associated tests include `TestCopyWithDryRun`, `TestCopyMissingDirectory`, `TestCopyFileBackupDir`, `TestCopyInplace` and max-transfer cases; inspected, not executed.

**Decision:** do not reuse upstream sync/copy as the plan executor. Our complete-scan marker, policy fingerprint, source/destination identities, explicit action bounds, ownership and preconditions belong in independent planning/execution code. Initial offline preview has zero cloud mutation and no deletion capability.

## Google Drive

**Observed:** `newFs` exposes `DuplicateFiles: true`, obtains config, OAuth and pacing state ([`backend/drive/drive.go:1372–1445`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L1372-L1445)); object data retains provider IDs ([`1533–1557`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L1533-L1557)). `list` queries parent IDs and requests next-page tokens and `incompleteSearch`. It iterates every page but **logs incompleteSearch and continues**, rather than returning a completeness error ([`1021–1065`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L1021-L1065), [`1118–1200`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L1118-L1200)). `FindLeaf` returns on the first matching name ([`1753–1773`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L1753-L1773)). These observed policies cannot resolve our duplicate-identity or complete-inventory requirements unchanged.

`shouldRetry` stops on context error, retries transient/5xx and rate-limit errors and has configurable quota-fatal rules ([`941–977`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L941-L977)). Native-document conversion can skip unexportable formats and has different checksum behavior ([`1662–1726`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive.go#L1662-L1726)). `TestDriveScopes` verifies default broad `drive` scope and parsing of narrower scopes; scope selection must be ours ([`drive_internal_test.go:35–58`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/drive_internal_test.go#L35-L58)).

`Upload` creates a resumable session or patches a known ID, keeps the session URI in memory, chunks repeatable readers, retries chunks and returns an incomplete-upload retry error if final metadata is absent ([`backend/drive/upload.go:53–111`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/upload.go#L53-L111), [`115–238`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/backend/drive/upload.go#L115-L238)). **Inference:** the inspected implementation alone does not provide LedgeSync's durable operation journal or approved-plan reconciliation after ambiguous create/final responses; this is not a repository-wide claim that no recovery mechanism exists elsewhere.

**Decision:** defer real Drive; introduce fake-provider contracts first. Later selectively adapt proven upload/retry mechanisms only after fake HTTP faults, app-specific OAuth identity/vault, duplicate IDs, complete pagination, session secrecy and crash reconciliation tests. Retain the additional Google-derived provenance at `upload.go:9` if that source is reused. `drive_test.go:13–23` invokes the real `TestDrive:` integration suite; it was deliberately not run. Internal export/scope fixtures were inspected, not run. No credentials or cloud calls were used.

## Concurrency, pacing and progress

**Observed:** the pacer has retry and connection bounds, replaceable calculator/invoker seams and defaults to unlimited connections ([`lib/pacer/pacer.go:31–128`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/lib/pacer/pacer.go#L31-L128)). `beginCall` waits on channels and a sleeping timer without a context parameter; retry loop similarly has no context argument ([`157–255`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/lib/pacer/pacer.go#L157-L255)). Provider callbacks check context, but waiting itself is not context-aware in this source. `accounting.Start` starts shared limiters and replaces `fs.CountError`; byte counters describe transfer progress, not durable remote verification ([`fs/accounting/accounting.go:33–109`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/accounting/accounting.go#L33-L109)).

**Decision:** independent job-scoped progress and cancellable bounded worker ports. Consider adapting pacer calculations later, with context-aware waits and fake-clock tests. `TestCall`, `TestCallParallel`, recursive deadlock regressions and `TestGoogleDrivePacer` were executed as part of the pacer package ([`pacer_test.go:185–233`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/lib/pacer/pacer_test.go#L185-L233), [`294–400`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/lib/pacer/pacer_test.go#L294-L400)). Accounting tests were inspected by test names and relevant setup only, not executed or fully reviewed.

## Authentication, configuration and library reuse

**Observed:** config discovery searches local executable, OS/XDG and home paths ([`fs/config/config.go:160–290`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/fs/config/config.go#L160-L290)). OAuth reads/writes tokens through the upstream mapper and token source rereads/refreshes stored tokens ([`lib/oauthutil/oauthutil.go:181–238`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/lib/oauthutil/oauthutil.go#L181-L238), [`245–379`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/lib/oauthutil/oauthutil.go#L245-L379)). The mechanism is tied to upstream configuration conventions.

`librclone.Initialize` installs the config file backend and starts accounting, while RPC dispatches registered calls into jobs with a background context ([`librclone/librclone/librclone.go:26–45`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/librclone/librclone/librclone.go#L26-L45), [`80–135`](https://github.com/rclone/rclone/blob/687d264b689b8c49a67e2e52a8a5e0caa01c04ce/librclone/librclone/librclone.go#L80-L135)). This is not a narrow approved-plan API. No tests establish LedgeSync compatibility for this path.

**Decision:** reject librclone and credential/config import. Use separate strict project configuration and later OS-vault OAuth integration with LedgeSync identity. Pure adaptation avoids the direct module's broad dependency declarations; actual transitive runtime size was not benchmarked.
